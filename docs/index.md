# mud-client Documentation

This directory is the end-user reference for the terminal MUD client.

- [Getting Started](getting-started.md): install, run, connect, and reload configuration.
- [Configuration Reference](configuration.md): every supported `config.toml` section and option.
- [Command Reference](commands.md): local `/` commands, command input behavior, and keys.
- [User Interface](ui.md): responsive layouts, panels, gauges, scrolling, mouse resizing, and color behavior.
- [Mapper](mapping.md): MSDP mapping, map commands, doors, terrain, pathing, and persistence.
- [Scripting](scripting.md): variables, aliases, triggers, highlights, events, Lua hooks, and safety limits.
- [Lua API Reference](lua-api.md): every exposed `client` API, hook context, editor-completion setup, and examples.
- [Lua Scripting Examples](lua-scripting-examples.md): copy-ready Lua alias, trigger, and event examples.
- [Troubleshooting](troubleshooting.md): common setup and runtime issues.
