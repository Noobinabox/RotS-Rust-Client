# `/help`

## Purpose

Display client help. Help is printed into the MUD output pane as local system output and is never sent to the server.

## Syntax

```text
/help
/help <topic>
```

Topics are case-insensitive. Topic aliases are accepted where documented, for example `paths` and `pathing` for `path`.

## Examples

```text
/help
/help map
/help path
/help map door
/help lua
/help panels
/help macro
/help save
/help vim
```
