# `/clear`

## Purpose

Clear retained MUD output and reset inherited ANSI styling. It does not clear map data, history, variables, or scripts.

## Syntax

```text
/clear
```

`Ctrl-L` is the keyboard equivalent.

## Examples

Clear the output pane after a long fight or debugging session:

```text
/clear
```

Old output is removed from scrollback; new MUD output continues normally. Your connection and command history are unchanged.
